# FIFA World Cup 2026 Schedule

A FIFA-style World Cup 2026 fixtures website built with:

- React
- Vite
- Tailwind CSS
- Lucide React
- Vercel

---

# Features

- FIFA.com inspired UI
- List view
- Calendar view
- Local stadium time
- UAE time toggle
- Search fixtures
- Filter by group
- Mobile responsive
- Ready for Vercel deployment
